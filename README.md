## Frequently Asked Questions

### Is this compatible with both Clip Studio Paint PRO and EX?

Yes, this toolkit is fully compatible with both Clip Studio Paint PRO and Clip Studio Paint EX editions. All included brushes, materials, and animation tools will work identically on either version.

### Will this affect my existing brushes and materials?

No. This toolkit is designed to complement your existing library. All new assets are added alongside your current brushes and materials without overwriting or modifying any of your personal configurations.

### What should I do if brushes don't appear after installation?

First, ensure Clip Studio Paint is closed during installation. If brushes are still missing, restart the application and check the brush sub tool palette. You can also manually import brushes via File > Import > Material. If issues persist, verify that your software is updated to the latest version.

### Can I customize which components get installed?

Yes. During installation, the wizard provides options to select specific brush packs or material libraries. This allows you to install only the components relevant to your workflow, saving disk space.

### Is this toolkit regularly updated?

The toolkit receives periodic updates with new brushes, materials, and compatibility improvements. Check back regularly or watch this repository for announcements regarding new releases.
